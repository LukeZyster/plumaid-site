# PlumAid Plumbing Solutions

A Next.js site for PlumAid Plumbing Solutions with booking, review, admin, and media features.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Scripts

- `npm run dev` — start the local app
- `npm run build` — production build
- `npm run start` — run the production build
- `npm run typecheck` — TypeScript validation
